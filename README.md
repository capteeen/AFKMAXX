# AFKMAXX

A dependency-free responsive landing page and shared product visual system.

- `npm run dev` serves http://127.0.0.1:4173
- `npm run check` checks JavaScript syntax, local links, assets, and duplicate IDs.
- `npm run build` copies deployable files to `dist/`.
- Open `system.html` for the six screen specimens, downloadable marks, and tokens.
- See `DESIGN-SYSTEM.md` for fonts, licenses, components, motion and product boundaries.

The site has no live backend. Demo settings and request previews are held only in memory. No traffic is routed, no emails are collected, and no payments are initiated. Pilot status is not yet open.
