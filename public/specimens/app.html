    LOAD THE RUNTIME

    ADD THE EXTENSION.

    1. Open chrome://extensions or Firefox about:debugging#/runtime/this-firefox.
    2. Enable developer / debug mode.
    3. Load unpacked (Chrome) or temporary add-on (Firefox) from the extension/ folder in this project.
    4. Open this web app on http://127.0.0.1 or http://localhost so the bridge can connect.
    5. Grant any extra hosts in the extension popup. example.com and example.org are pre-allowed.

    Without the extension, this page can save settings but cannot read third-party HTTPS responses. That is a browser rule, not a missing button.
